# Как перейти на новую версию

Проект переписан по замечаниям: тема `tesla_parameters`, поля — сила тока и
мощность, фильтр двойным слайдером, белая палитра, переделанные лента
и страница добавления.

---

## 1. Заменить файлы

Останови приложение (`Ctrl` + `C`). В папке `D:\rip\labs\tesla-charge`:

- **удали** папку `src\tesla_charge` целиком;
- **удали** старые шаблоны `views\feed.hbs`, `views\draft.hbs`, `views\modes.hbs`;
- скопируй из архива с заменой: `src`, `views`, `public`, `scripts`,
  `docker-compose.yml`, `tsconfig.build.json`, `.env`;
- проверь, что в `package.json` остался скрипт
  `"migrate": "ts-node -r dotenv/config scripts/migrate.ts"`.

Папку проекта переименовывать не обязательно — на оценку влияют названия
в коде, а не на диске. Если хочешь, можешь переименовать её в
`tesla-parameters` и заново открыть в VS Code.

## 2. Пересоздать бакет Minio

Имя бакета входит в адреса файлов, поэтому оно тоже переименовано.

1. `docker compose up -d`
2. Консоль `http://localhost:9001`, логин и пароль `minioadmin`.
3. Создать бакет **`tesla-parameters`**.
4. Бакет → Anonymous → Add Access Rule → Prefix `/`, Access `readonly`.
5. Загрузить те же 10 файлов из `D:\rip\media`.
6. Старый бакет `tesla-charge` можно удалить.

Проверка: `http://localhost:9000/tesla-parameters/highway_cruise.jpg`
открывает картинку.

## 3. Пересоздать таблицы

Старые таблицы называются по-другому и больше не нужны. В Adminer
`http://localhost:8081` (PostgreSQL / `postgres` / `tesla` / `tesla_password` /
`tesla_charge`) выполни в разделе «SQL-запрос»:

```sql
DROP TABLE IF EXISTS driving_mode_likes;
DROP TABLE IF EXISTS driving_modes;
DROP TABLE IF EXISTS drivers;
```

Затем в терминале:

```
npm run migrate
```

И снова в Adminer выполни содержимое `scripts\seed.sql`.

## 4. Запустить

```
npm run start:dev
```

Открывай `http://localhost:3000/parameter-feed`.

| Было | Стало |
| --- | --- |
| папка `src/tesla_charge` | `src/tesla_parameters` |

### Поля по теме

Средняя скорость и расход энергии заменены на **потребляемую силу тока** (А)
и **потребляемую мощность** (Вт). Фильтрация — по силе тока.

| Параметр | Ток, А | Мощность, Вт | Статус |
| --- | --- | --- | --- |
| Движение по шоссе 120 км/ч | 55,0 | 22000 | опубликован |
| Городской цикл с рекуперацией | 22,5 | 9000 | опубликован |
| Обогрев салона при минус 15 | 10,0 | 4000 | опубликован |
| Подогрев сидений и руля | — | — | черновик |
| Кондиционер при плюс 35 | 6,3 | 2500 | удалён |

Ток получен делением мощности на напряжение батареи Model S — 400 В.
Перед сдачей сверь мощности с реальными источниками.

### Лента

- описание внизу: две строки и ссылка **«Ещё»**, в развёрнутом виде «Свернуть»;
- справа колонкой: сила тока, мощность, иконка лайка с количеством
  и круглая синяя кнопка «Далее» — переход к следующему параметру.

### Страница добавления

- до нажатия «Далее»: выбор фото и видео из **списка файлов бакета Minio**
  (два выпадающих списка друг под другом) и название;
- после создания черновика: показываются выбранные фото и видео, а вводятся
  только недостающие поля — описание, сила тока, мощность, кнопка
  «Опубликовать».

Список файлов читается прямо из Minio: приложение запрашивает перечень
объектов бакета по протоколу S3. Если Minio выключен, списки будут пустыми.

### Фильтр

Двойной слайдер: нижняя и верхняя границы силы тока, диапазон 0–60 А с шагом
0,5. Выбранные числа показываются над ползунками **после нажатия кнопки
«Показать»** — без JavaScript значение во время перетаскивания не обновляется.
Границы сохраняются после запроса и видны в адресе:
`/parameters?minCurrent=5&maxCurrent=30`.
